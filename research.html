DOCUMENTED EXPERIMENT · REPOSITORY-REPORTED RESULTS

numeric-lora: verifiable numerical reasoning

A QLoRA instruction-tuning pipeline using machine-checkable arithmetic, generated worked solutions, and exact-ground-truth scoring. The repository documents experiments with Qwen2.5-7B-Instruct on insurance problems.

Repository README results on 100 held-out insurance problems; experiments were not rerun for this website update.
Model / training targetAccuracy
Base model86%
QLoRA · collapsed solutions57%
QLoRA · step-by-step worked chains90%

The reported comparison uses greedy decoding, a 768-token budget, and 0.5% relative tolerance; the README reports zero truncation for the compared runs. The evaluation set is unseen but drawn from the same problem generators as training.

This small, in-distribution experiment does not establish out-of-distribution generalization or robotics capability. The change from 86% to 90% is four percentage points; results should be read alongside target-format effects and per-category sample sizes.

Source: numeric-lora repository README, reviewed October 9, 2026. The repository is currently private.

WORK IN PROGRESS · v0.1

ReturnOps-Bench: policy-constrained agent evaluation

A simulated retail returns environment in which an agent uses tools to inspect orders, read policies, wait for logistics events, and settle a customer ticket. Evaluation checks the final ledger to the cent, return-line status, escalations, and policy violations.

The current README describes nine implemented tasks across allocation, policy interpretation, asynchronous fulfillment, tender handling, and abuse detection. A tenth task, tender-t2, still requires an exchange tool.

Current documented baselines are scripted agents: an oracle, random actions, always-deny, and naive-refund policies. These are environment checks and baseline evaluations, not demonstrated LLM or robot performance.

This is an evolving software benchmark, not a completed robotics system. Its connection to my future interests is evaluation of sequential decisions under constraints.

Source: ReturnOps-Bench README, reviewed October 9, 2026. The repository is currently private.
